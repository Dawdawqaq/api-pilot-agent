# 真实联调合成资料

这些文件为 `[E2E_TEST]` 项目提供独立目标，不用于生产业务。`npm.cmd test` 只跑前端回归，不会启动此服务、写入数据库或调用收费模型。

## 复测步骤

1. 按项目启动说明启动 DocHelper 的共享基础设施、后端和新版前端。后端知识库需要真实对象存储和向量库。前端默认代理 `127.0.0.1:18081`；IDEA 后端用其他端口时按前端 README 设置 `DOCHELPER_BACKEND_URL`。不要停止其他项目容器或删除共享卷。
2. 在独立 PowerShell 终端启动无第三方依赖的合成目标，保留终端查看请求日志：

   ```powershell
   # 在仓库根目录执行。
   python frontend/tests/integration/target_server.py
   ```

   仅监听 `127.0.0.1:18770`。端口冲突时先识别现有服务，不要结束不明进程；本资料和环境 URL 使用固定端口，修改时须同步环境地址。按 Ctrl+C 停止。
3. 在真实模式创建带 `[E2E_TEST]` 名称的项目和环境，环境地址 `http://127.0.0.1:18770`。此本地目标需要明确允许私网访问，并允许测试所需 GET、POST。依次导入 `openapi-v1.json` 和 `openapi-v2.json`，检查历史版本中 `/legacy-records` 仅在 v1 出现。
4. 知识库启用时上传 `business-rules.md`，等到 INDEXED 后检索记录业务规则。只验证存储及引用链路；确定性嵌入不能证明语义质量。
5. 真实模型会将允许的项目资料发往已配置供应商并消耗额度。需使用者明确选择真实 API 模式及项目资料策略，不能把此步骤放进默认自动测试；不要把 API Key 写入资料、脚本或证据。
6. 用只读目标验证列表 GET；用“创建标题为 `[E2E_TEST] 原标题` 的记录，查询详情并校验标题”验证计划修改、批准与 POST→GET 提取。目标 ID 为超过 JavaScript 安全整数范围的字符串，可核对精度。等待人工确认期间、拒绝或取消后，检查目标请求记录没有意外写入。
7. 在浏览器检查报告和 JUnit XML 下载。模拟网络离线再恢复，核对 SSE 游标、状态刷新及临时错误清除。删除仅本次新建的临时文档/环境/空项目；不要批量清理已有验收项目。

## 目标接口

| 请求 | 参数 | 成功响应 / 异常 |
| --- | --- | --- |
| GET `/records?limit=10` | OpenAPI 将 limit 定义为必填整数；合成服务用于链路验证，没有实现完整参数校验及分页 | `{records: [], count: 0}`，有记录时返回对应内容 |
| POST `/records` | JSON 对象，必填非空 `title` | `{id: "9223372036854700000", title: "..."}`，HTTP 200；JSON 非法或 title 缺失为 400 |
| GET `/records/{id}` | 原样使用上一步返回的字符串 ID | 存在返回记录，缺失为 404 |
| GET `/legacy-records` | v1 历史资料接口 | 同列表响应，仅用于历史版本切换检查 |
| GET `/__test__/state` | 无 | `{requests: [...], records: [...]}`，读取此检查接口本身不增加请求记录 |

检查目标状态的完整命令：

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:18770/__test__/state | ConvertTo-Json -Depth 10
```

数据仅在目标进程内存中，停止后清空。后端任务、文档与报告使用 DocHelper 自身持久化，目标停止不会删除它们；历史详情可以继续查看，旧记录的 GET/回放可能因目标已重置而返回 404。这是复测环境变化，不应伪装为业务成功。

损坏资料复测：创建非空但非法的 `.json` / `.pdf` 文件，上传后应看到真实错误、失败记录和重试入口。OpenAPI 重试生成新版本，文档重试保留同一文档身份；不支持的文件类型可能在入库前被拒绝，不应假设每个错误都会产生记录。
